# Windows 分发资料位置

本说明针对便携发布包，不改变源码仓库结构。

- 主 MIT 原文：发布根目录 `LICENSE`。
- 第三方许可证原文：本 `licenses/` 目录。
- 项目使用与声明资料：`licenses/project-docs/`。
- 来源、历史授权及合规记录：`licenses/licensing/`。
- 原生组件对应源码与原始声明：`licenses/third-party/`。

这些资料为保留原始声明而集中存放，不属于可随意删除的安装缓存。PCL 目录架构参考说明仍为本目录的 `PCL-DIRECTORY-ARCHITECTURE-REFERENCE.md`，不包含 PCL 源码或资源。

部分历史记录中的相对路径以源码仓库根目录为基准；公开源码中的 `licenses/`、`licensing/`、`third-party/` 目录保持原结构。
