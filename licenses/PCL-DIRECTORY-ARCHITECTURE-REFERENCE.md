# PCL 目录架构参考鸣谢

XG Launcher 的 Minecraft 版本隔离目录组织参考了 PCL（Plain Craft Launcher）的目录架构思路：按版本管理游戏配置、模组、光影、资源包、存档及日志，公共资源和运行时由启动器共用；不在版本目录中再嵌套一层 `versions`。

参考项目：https://github.com/Meloong-Git/PCL
原项目地址：https://github.com/Hex-Dragon/PCL2 （现重定向至上述仓库）

此项属于目录架构思路参考鸣谢。本次未复制、改编或分发 PCL 源码、图标、界面资源或二进制；XG Launcher 的实现基于自身既有代码及 CmlLib 的公开扩展接口。此说明不是 PCL 的许可证正文，也不声称 PCL 采用 MIT 或已授权任何 PCL 内容。

XG Launcher 自有代码继续采用原有 MIT 主许可证；现有第三方内容分别遵守其原许可证。本鸣谢不表示 PCL 官方认可、合作或赞助。
