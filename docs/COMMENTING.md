# 中文注释与源码规范

保留英文标识符、命名空间、资源键、JSON字段、持久化状态和接口路径，使用简体中文解释业务规则。统一UTF-8，尊重文件原换行和原有SPDX/第三方版权头；不为格式统一重排无关代码。

重要公共类型和复杂入口采用标准C# XML文档。summary说明实际职责；只有需要解释的参数和返回值才用param/returns；exception只记录代码真实抛出的异常，不猜测调用栈中所有可能异常。复杂参数若已开始逐项说明，应确保名称与签名一致。

注释优先说明原因、边界、取消和释放顺序、兼容性及易回归点，不逐行复述赋值。不要将注释中的目标当成已经实现的功能，不写无法由代码支持的线程安全保证。

下载队列集合并非通用并发容器；底层TransferGate锁、共享任务字典和AsyncLocal父子上下文各有独立作用。调用方需遵守现有调度上下文，UI订阅者负责切回UI线程；不能把其中一种机制描述成整个下载服务已完全加锁。

认证注释区分公开应用标识与机密凭据；不在源码、文档、样例或测试中加入真实令牌、回调参数、密码或私钥。日志脱敏只作用于诊断输出，不得把脱敏结果用于实际认证、文件路径或启动参数。

无轨道阶段节点仍绑定真实事件。隐藏连接线不删除定位轴；UI短名称不改Kind；完成记录不等于预选加载器；DIP几何和无头缩放检查不等于Windows原生DPI实机结果。

不要翻译第三方许可证正文或改变原版权归属。历史文档中的旧阶段和旧许可说明用于追溯，当前README、授权范围与已知问题应指向现状。
