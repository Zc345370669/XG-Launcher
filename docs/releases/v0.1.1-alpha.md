# XG Launcher v0.1.1-alpha

- 接入 GitHub Releases 自动更新：启动检查，设置 → 关于页点击版本号手动检查。
- 更新弹窗显示真实下载进度与校验状态，支持取消；安全退出后替换 EXE 并重新打开。
- 更新仅替换启动器，保留账号、存档、模组、配置、游戏资源及 Java；校验、路径白名单和失败回滚保护保留。
- 关于页隐藏仓库地址下方重复的 MIT、第三方许可及导出按钮，统一在现有“许可证与鸣谢”页查看、导出。
- 发布 ZIP 结构为 `XG-Launcher/XGLauncher.exe`；MIT、Lucide ISC、适用第三方声明及对应源码材料内嵌并可离线导出。

## 更新与运行

解压后运行 `XG-Launcher/XGLauncher.exe`。首次使用本次更新协议的旧客户端可能需要手动替换 EXE 一次；请保留原有数据目录并事先备份重要存档。

## 验证范围与已知限制

Windows CI 包含 Release 构建、核心与无头 UI 回归、许可与公开源码扫描、独立更新器进程测试及隔离公网 Release 下载、校验、替换与原生窗口启动测试。CI 测试不等于玩家设备的完整人工 GUI 验收。

尚未完成移动硬盘物理拔出、真实断电、全部 DPI、多显示器、UAC 与杀毒软件场景的人工验收。进程在写入前被终止后的重试不等于断电恢复保证。

Microsoft 正版登录仍受应用审核／Minecraft Services 资格限制，可能返回 HTTP 403；本版本没有绕过认证或将该问题标记为已解决。
