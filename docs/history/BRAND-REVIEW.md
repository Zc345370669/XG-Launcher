# 名称与标志初步核对

- 以“瞎搞启动器”“XG Launcher”做了公开网页精确词组初筛。返回结果中未识别到直接对应的同名 Minecraft 启动器。普通网页的覆盖范围有限。
- 按确认稿保留几何连体黑色 XG Logo，程序和安装包不采用 Minecraft 草方块图标。README 提供独立第三方声明。[Minecraft Usage Guidelines](https://www.minecraft.net/en-us/usage-guidelines)
- “XG”只有两个字母，公开发行前仍需核对软件类同名或近似商标和图形。普通网页初筛尚未覆盖具体注册记录，也尚未完成图形近似检索。[智利 INAPI 检索](https://buscadormarcas.inapi.cl/) · [WIPO Global Brand Database](https://branddb.wipo.int/)
