# Windows x64 正版登录实机记录

本轮环境为 Linux x64。Windows 便携版已交叉发布，尚未在 Windows 实机运行。没有真人提交微软账户凭据，也没有取得 Xbox、XSTS 或 Minecraft 游戏令牌。

Windows 复测入口为 `portable-win-x64/XGLauncher.exe`。点击账号与微软正版登录，确认系统浏览器的官方微软域名；完成授权后，核对返回的玩家名称和 UUID、Java 权益与游戏主菜单。再验证关闭浏览器后可点取消、重新登录、切换账号、删除单账号、重启后的 Windows 缓存读取和会话刷新。

若见 403，请记录阶段、数字状态码及界面分类。账号凭据、Cookies、授权码、完整授权 URL 和含令牌的 Java 命令应留在本机。现有界面截图为 Linux 无头运行生成。
