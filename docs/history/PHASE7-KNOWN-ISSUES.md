# 第七阶段已知问题

- Windows x64 GUI、当前用户 DPAPI 实际写入和重启后的缓存解密待 Windows 实机验证。
- 真人微软浏览器登录、成功授权回调、Xbox Live、XSTS、Java 权益、玩家档案、真实令牌刷新与正版游戏进程待实测。当前获知的 Entra ID 和真实 302 入口跳转不能确认 Minecraft API 审批。
- 已验证 launcher 管理的 `xg-launch.log` 的常见敏感字段、游戏令牌与所选玩家资料遮盖。Minecraft 或模组自行写入的其它日志不由启动器过滤。Java 游戏协议所需令牌仍由启动参数传送，本机有权限检查该进程的主体可能看到该参数。
- 重新打开程序后，需要在账号面板选择已保存的微软账号才能切换到该会话。单账号删除仅清理本启动器缓存。
