# v0.1.0-alpha

- 同一启动器内提供完整模式和精简模式，共享账号、实例、下载、启动和主题状态。
- 精简模式在游戏组合框内选择实例或选择版本及加载器安装，账号选择与添加采用共享服务。
- 实例按版本隔离，公共依赖复用；目录组织参考 PCL，范围见 licenses/PCL-DIRECTORY-ARCHITECTURE-REFERENCE.md。
- 下载卡片保留唯一总进度条、无连接线阶段节点、实际加载器名称和阶段接力效果。
- Java 与加载器安装使用现有静默进程配置；验证成功后仅清理任务拥有的安装资料。
- 项目自有代码和文档采用标准 MIT；Lucide ISC、Feather MIT、原生 GIF 对应源码与 MPL 原文，以及其他第三方和历史授权记录继续保留。

Microsoft/Minecraft 服务访问申请已提交，正在等待审核；HTTP 403 尚未确认解决。Windows GUI、真实游戏及账号、DPI 和多显示器验证以实际记录为准，交叉发布成功不代表实机通过。详见 docs/KNOWN_ISSUES.md。

- 下载中或暂停后可确认保存任务并退出，下次从下载管理恢复；共享传输在退出前释放文件句柄。
- 启动时检查官方 Release；“设置 → 关于”的版本号文字提供手动入口。校验更新包后由独立更新程序替换旧主程序，保留用户数据。

此页面归档最初公开的 0.1.0-alpha 源码。此前没有公开的 0.1.0-alpha 安装包。请在 [最新发布](https://github.com/Zc345370669/XG-Launcher/releases/latest) 下载当前 Windows 版。
