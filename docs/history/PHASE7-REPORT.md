# XG Launcher v0.1.0-alpha 第七阶段

唯一开发基线为 `XGLauncher_phase7_oauth_configured_source.zip`，SHA-256 为 `dd4b3e89cc6dd94954237b030ff952340a8f04930006d4e6fb9a0c05599524d8`。保留包内已配置的公开 Entra Client ID。构建主机 Linux x64，目标 Windows x64，.NET SDK 10.0.404，Avalonia 11.3.23，MSAL 4.61.3。

## 源码修改

- 提供可主动取消的系统浏览器登录流程和账号操作互斥。MSAL 使用临时 localhost 回环、state 及授权码加 PKCE，应用内不获取微软密码。
- 区分 Xbox Live、XSTS、Minecraft 会话、权益及档案错误。处理 HTTP 401、403、429 和 5xx。只显示白名单分类和状态码，避免把服务的原始响应写入日志。
- 支持移除单个缓存账号。失败时保留旧账号；浏览器新增账号的 Minecraft 校验若失败，尝试清理这次新增的未验证缓存。已有缓存账号选择失败时不清理存量。
- 启动前固定所选账号，当游戏下载完成后查询或刷新 Minecraft 会话。期间切换账号会中止本次启动。游戏会话显式使用 `msa`；第一轮真实安装后的参数断言失败，上游 CmlLib 对空会话类型回退为 `Mojang`，修复后同一路径复测通过。启动器过滤自己接管的游戏输出日志。
- 保留第六阶段 UI、目录、整合包、下载与设置组件。对应核心文件及资源的逐字节核对见 `baseline-check.log`。账号面板增加取消和删除操作。
