# 历史开发记录

本目录存放 XG Launcher 早期阶段报告、微软 OAuth 403 诊断、品牌检查和旧版发布草稿。归档仅用于保存历史，不代表当前版本的实现、测试状态或许可证。

## 分类

- `PHASE*.md`、`V6-CHANGELOG.md`：早期开发阶段和变更记录。
- `OAUTH-403-*.md`、`OAUTH-FIX-REPORT.md`、`OAUTH-WINDOWS-VERIFICATION.md`、`AUTH13_1.md`：微软登录问题的历史诊断与验证。
- `BRAND-REVIEW.md`：历史品牌审核记录。
- `RELEASE-DRAFT.md`：旧发布草稿。
- `README-before-alpha-release.md`：早期项目说明快照。

当前项目说明以仓库根目录 `README.md` 为准；许可证与第三方权利信息以根目录正式声明和 `licenses/`、`licensing/` 中适用的文件为准。历史报告中的未完成验证事项，不应视为已通过测试。
