# v0.1.0-alpha 已知问题与验证边界

- Microsoft正版登录可能在Minecraft Services返回HTTP403，尚未确认解决。维护者已提交服务访问申请，正在等待审核；保留现有错误反馈，应用注册与服务资格仍需合法核实。
- MSAL回调完成不代表Xbox、XSTS、Minecraft所有权和玩家档案检查全部成功。完成页不能清除浏览器、代理或系统已经产生的历史记录。
- 当前开发验证在Linux执行；Windows EXE交叉发布成功不等于实际Windows GUI通过。真实游戏启动、正版账号、安全缓存、真实网络安装、多显示器、系统DPI切换和原生合成效果尚需Windows验证。
- Windows11圆角只是DWM偏好，实际效果由窗口条件和合成器决定；Windows10及不支持的路径保留直角边界。毛玻璃受平台能力限制，不支持时回退。
- 本地实例就绪要求安装凭据、配置、必要文件与Java校验，不能仅创建文件夹或看到100%就认为已安装。
- Modrinth及官方版本、认证、加载器服务需要网络；自动测试中使用的受控HTTP和资源记录不能证明所有真实版本、账号或加载器组合可用。
- 文件安全扫描采用明确规则及逐项例外复核，不能证明不存在所有未知格式的秘密。本次交付ZIP不含Git历史，不能据此声明远程仓库历史已排查。若后来发现曾提交真实凭据，应从源码移除并撤销/轮换，再处理历史，不能只增加gitignore。
- 用户存档、账号、实例、日志和崩溃报告不属于源码；发布前请在干净目录解压源码包检查文件清单。Alpha版本使用前备份重要用户数据。

Windows 原生八向缩放、Snap、最大化工作区及跨不同 DPI 显示器拖动仍需实机检查。每次构建与测试结果以对应验证包日志为准。

- 在线更新目前已完成受控 HTTP、文件事务及无头交互验证，真实 GitHub Release 网络下载、Windows 更新器启动、文件占用/权限和重启尚未实机验证。公开版本需手动发布并提高版本号。
