# 当前 MIT 权利决定

**B：仍存在具体授权阻碍，尚未切换。** 未来目标是标准 MIT，当前应用仍 GPL-3.0-only。XGCL 不再是未来目标，v14 记录仅作历史保存。

B1 的完整范围是 APPLICATION-RELICENSING-CHECKLIST.json 的 112 个精确路径/散列，不是要求把所有文件重新编写。没有发现某位外部贡献者或确定的外部 GPL 复制；缺口是有权人的真实范围确认及准确版权署名。可用覆盖 manifest 的单份确认与例外清单解决，不能把“决定选 MIT”自动当成取得他人许可。

B2 限定 MainWindow.cs 六导航/两工具栏路径和 TitleBar.cs 四种标题栏路径。现有 ISC/MIT 声明完整，但图形源头仍须按散列对应。不以通用形状或没有署名直接判侵权，也不直接推定无版权。

B3 是 libSkiaSharp.dll/libHarfBuzzSharp.dll 的原生分发合规条件，而非已证明自有应用不能采用 MIT。本轮从精确包元数据定位官方提交并查看 Windows 构建脚本；脚本有额外 GN 参数入口，不能仅凭仓库默认配置断言 NuGet 实际二进制包含哪些子组件或采用何种许可。保留完整原文并请求实际构建/SBOM/许可对应即可继续缩小范围。

每项的文件、缺口、原因和下一步均在 FINAL-REVIEW.json。版权年份/公开署名尚未确认，不虚构“所有贡献者”或真实姓名。确认后只需按 MIT-MIGRATION.md 更新适当授权文件及资源映射，无需再重写 Java 或改 UI。

现行 GPL 本身并不禁止商业销售，但当前副本仍应遵守其源码提供等有效条件；未来合法 MIT 允许的闭源再分发不能提前套用于这些未切换的 GPL 副本。第三方许可也不会自动变成 MIT。
