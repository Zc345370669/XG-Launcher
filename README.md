# XG Launcher（瞎搞启动器）

Minecraft Java 版启动器，适用于 Windows 10/11 x64。

**当前本地开发版本：v0.1.2（尚未上传或发布）** · [下载 Windows 版](https://github.com/Zc345370669/XG-Launcher/releases/latest) · [本地更新说明](CHANGELOG_v0.1.2.md) · [历史版本](docs/history/README.md)

## 使用

1. 从发布页下载 `XGLauncher.exe`，放在自己的启动器文件夹中并运行。程序无需另外安装 .NET。
2. 在「个人游玩」创建或导入实例。导入可自动校验并补齐缺失资源，准备就绪后手动启动。
3. 旧版用户可在「设置 → 关于」点击版本号检查更新。也可以关闭启动器后，在原有文件夹里替换 EXE。

完整模式提供实例、整合包、模组和下载管理。精简模式与完整模式共享账号、实例、主题及下载状态。支持离线账号和 Microsoft 正版账号。已知登录及平台限制见 [已知问题](docs/KNOWN_ISSUES.md)。
